NEXO26 Studio

NEXO26 Studio es la consola operativa privada para fundadores y operadores. Ejecuta la base de datos local SQLite, la orquestación multi-agente y el ledger inmutable de decisiones.

ESTADO DE ACCESOProtegido por RBAC multi-rol (Fundador, Admin, Operador)
HOSTING REQUERIDOPara acceso remoto permanente, configure las credenciales de despliegue en Vercel/Render
EJECUCIÓN LOCALDisponible en la máquina del Fundador mediante npm run dev
